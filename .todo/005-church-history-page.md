# 교회 역사 페이지 이관 및 반응형 타임라인

- 상태: 대기
- 유형: 페이지

## 목적

레거시 교회 역사 소개와 연혁을 현재 프로젝트로 이관하고, 스크롤 중 이미지가 화면 배경으로 전환되는 기존 방식 대신 데스크톱과 모바일에서 연혁 사진과 설명을 명확히 읽을 수 있는 반응형 타임라인을 구현한다.

## 참고 기준

- 레거시 페이지: `legacy-frontend/src/pages/introduce/Greetings/Greetings.jsx`
- 레거시 타임라인: `legacy-frontend/src/components/Timeline/Timeline.jsx`, `Timeline.module.css`
- 레거시 이미지: `legacy-frontend/src/pages/introduce/Greetings/img/`
- 현재 페이지 및 라우트: `frontend/src/pages/ChurchHistory/ChurchHistory.tsx`, `frontend/src/app/router.tsx`
- Navbar 항목: `frontend/src/shared/config/navbar-items.ts`
- 페이지 콘텐츠 API·CMS 패턴: `frontend/src/shared/api/cmsApi.ts`, `frontend/src/pages/Admin/Pages/Visit/`, `backend/services/page_content_service.py`

레거시 프로젝트의 컴포넌트나 URL을 런타임에서 참조하지 않는다. 다크모드는 추가하지 않는다.

## 작업 범위

1. `/about/church-history`의 페이지 이름 placeholder를 실제 교회 역사 페이지로 교체하고 기존 Navbar 경로와 공용 레이아웃을 유지한다.
2. 레거시 교회 소개 문구와 연혁 5건의 날짜·사건 설명·사진을 보존한다.
   - 2013.05.12: 동베를린 담임목사 사택에서 개척예배 시작
   - 2013.10.25: Bundesplatz에 위치한 교회에서 창립예배
   - 2015.01.25: Alexanderplatz로 예배당 이전
   - 2020.12.13: Pankow의 Hoffnungskirche로 예배당 이전
   - 2021.07.04: Mitte의 Theologisches Konvikt으로 예배당 이전
   - 소개 문구에 포함된 성경 구절과 지역사회 섬김에 관한 내용을 보존한다.
3. 레거시 연혁 사진 5장을 현재 프런트엔드의 정적 자산으로 이관해 초기 콘텐츠에 사용한다. 기존 `background.jpg`를 스크롤에 따라 바꾸는 고정 배경 효과는 이관하지 않는다.
4. 콘텐츠는 프런트엔드 번역 맵에 하드코딩하지 않는다. 버전 관리되는 교회 역사 초기 콘텐츠를 기존 페이지 콘텐츠 API의 기본값으로 제공하고, 지원 언어별 콘텐츠를 CMS에서 편집할 수 있도록 연결한다.
   - 한국어·영어·독일어 소개 문구와 연혁 내용을 제공한다.
   - 관리자는 연혁을 추가·수정·삭제하고 순서를 변경할 수 있다.
   - 연혁별 날짜, 제목 또는 설명, 사진을 관리할 수 있다.
   - 사진은 기존 미디어 API와 업로드·교체·삭제 정리 방식을 사용한다. 언어별로 연혁 텍스트를 편집하더라도 같은 연혁 사진은 공유한다.
   - 기존 optimistic revision 및 충돌 처리 패턴을 따른다.
5. 교회 역사 페이지를 backend `page_catalog`와 프런트엔드 관리자 페이지 트리에 등록하고, `/admin/pages/church-history` 편집 화면과 관리자 메뉴·할당 설정을 연결한다.
6. 디자인은 현재 공통 CSS 토큰과 글꼴을 사용한다.
   - 데스크톱에서는 중앙 세로 연혁 축을 기준으로 이미지 포함 카드가 좌우 교차 배치된다.
   - 모바일과 좁은 화면에서는 한 열 세로 타임라인으로 표시하고 사진과 텍스트를 카드 안에 함께 배치한다.
   - 사진은 연혁 카드의 콘텐츠로 보여주며 전체 화면 고정 배경, 스크롤에 따른 배경 이미지 교체, 가독성을 낮추는 blur 효과에 의존하지 않는다.
   - 콘텐츠가 스크롤 위치나 `IntersectionObserver` 활성화 상태에 따라 숨겨지거나 흐려지지 않게 한다. 모션은 필수 정보나 조작에 사용하지 않는다.
7. 정적 UI 문구는 기존 언어 처리 규칙에 따라 한국어·영어·독일어를 지원하고, CMS 콘텐츠는 기존 언어 fallback 동작을 따른다.

## 제외 범위

- 담임목사 소개, 교회 비전, 새누리 소식 페이지 변경 또는 페이지 통합
- Home·예배 및 오시는 길 페이지 변경
- 레거시의 고정 배경 타임라인, 스크롤 기반 배경 교체 및 blur 활성 효과 이관
- 새 데이터 소스, 외부 이미지 URL 의존성 또는 별도 백엔드 서비스 추가
- 다크모드 추가

## 완료 조건

- `/about/church-history`에서 레거시 소개 내용과 연혁 5건 및 대응 사진을 확인할 수 있다.
- 콘텐츠 기본값은 버전 관리되며, 프런트엔드에 페이지 본문 번역 맵을 두지 않는다.
- CMS에서 지원 언어별 소개·연혁 텍스트를 관리하고 연혁 항목의 추가·수정·삭제·순서 변경이 가능하다.
- 연혁 사진은 기존 미디어 처리 방식을 통해 업로드·교체·삭제할 수 있고 언어 간에 공통으로 유지된다.
- 페이지 콘텐츠와 미디어가 기존 페이지 API, CMS 권한·할당, 저장 revision 및 충돌 처리 규칙을 따른다.
- 데스크톱 타임라인은 이미지가 포함된 좌우 교차 카드로 읽히고, 모바일에서는 한 열로 자연스럽게 재배치된다.
- 어떤 화면 크기에서도 연혁 사진이 고정 배경으로 가려지지 않으며 날짜와 설명을 스크롤 상태와 무관하게 읽을 수 있다.
- 사용자 노출 문구와 CMS 콘텐츠가 한국어·영어·독일어 및 기존 fallback 규칙을 따른다.
- 색상은 공통 CSS custom property를 사용하며 레거시 경로나 외부 이미지 URL에 의존하지 않는다.
- 관련 frontend/backend 테스트, 타입 검사 및 lint가 통과한다.

## 검증

- 초기 페이지 API 응답의 언어별 seed와 fallback 확인
- CMS에서 연혁 항목 추가·수정·삭제·재정렬 및 사진 교체 후 공개 페이지 반영 확인
- 저장 revision 충돌 처리와 더 이상 참조되지 않는 업로드 미디어 정리 확인
- 데스크톱 좌우 교차 배치 및 모바일 한 열 레이아웃 확인
- 스크롤 위치에 상관없이 각 연혁 사진·날짜·설명이 표시되는지 확인
- 관련 frontend/backend 테스트, frontend 타입 검사 및 lint 실행
