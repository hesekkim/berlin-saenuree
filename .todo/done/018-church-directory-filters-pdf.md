# 018. 교회 명부 필터 및 PDF 출력

- 상태: 완료
- 유형: 기능 추가
- 선행 작업: 016 교회 명부 CMS

## 목적

관리자가 생일 월 등으로 명부를 찾고, 선택한 회원이나 현재 필터 결과를 PDF로 저장할 수 있게 한다.

## 범위

1. 생일 월과 이름 검색으로 명부를 필터링한다. 생일 월은 출생 연도와 관계없이 월·일 기준으로 적용한다.
2. 필터 조합은 동시에 적용하고 결과 수를 제공한다. 생일 월이 선택되면 생일 날짜순, 아니면 이름순으로 정렬한다.
3. 현재 필터에 해당하는 회원을 페이지네이션 전 목록에서 계산하고, 필터 변경 시 첫 페이지로 이동한다. 선택은 필터와 페이지 이동 사이에서 유지한다.
4. 명부 조회 권한이 있는 사용자에게 회원 선택과 현재 페이지 전체 선택을 제공한다. 읽기 전용 사용자는 선택 및 PDF 출력만 가능하고 삭제·편집은 할 수 없다.
5. 필터는 적정 폭으로 좌측에 배치한다. 결과 수는 필터 옆에, 선택 수·삭제·단일 PDF 저장 버튼은 같은 줄 오른쪽에 모은다. 모바일은 기존 목록 헤더의 선택 컨트롤을 유지한다.
6. 저장 버튼을 누르면 Dialog에서 체크한 회원 또는 현재 필터 결과 전체를 선택할 수 있게 한다. 필터가 없을 때 전체 결과는 전체 명부를 대상으로 한다.
7. 선택 결과를 브라우저 인쇄 화면으로 출력해 사용자가 PDF로 저장할 수 있게 한다.
8. PDF에는 이름·생년월일과 등록된 이메일·전화번호를 포함하고, 이메일에 생년월일보다 넓은 열 너비를 할당한다. 출력 제목, 필터 요약, 생성 날짜를 표시한다.
9. 정적 UI 문구는 한국어·영어·독일어를 지원하고, 모바일에서도 필터와 출력 동작을 사용할 수 있게 한다.

## 완료 조건

- 생일 월 필터가 출생 연도에 상관없이 해당 월의 회원만 반환한다.
- 이름 검색과 생일 월 필터를 함께 사용할 수 있고, 필터 결과 수와 빈 결과가 올바르게 표시된다.
- 현재 페이지 선택, 페이지 간 선택 유지, 필터 변경 후 페이지 조정이 기존 페이지네이션과 일관된다.
- 조회 권한이 있는 읽기 전용 사용자도 선택·출력할 수 있지만 회원 편집·삭제는 할 수 없다.
- 단일 저장 버튼을 통해 출력 범위를 선택하고, 선택 개수와 현재 필터 결과 개수가 올바르게 표시된다.
- 선택 출력은 선택된 회원만, 전체 출력은 현재 필터 결과 전체를 포함하며 페이지 제한을 받지 않는다.
- 출력물에 등록된 연락처가 포함되고, 한글 및 여러 페이지 출력이 올바르게 보인다.
- 인쇄 표에서 생년월일 열보다 이메일 열이 넓다.

## 검증

- 프런트엔드 단위 테스트: 생일 월 경계, 이름·생일 월 필터 조합, 페이지와 선택 상태 및 읽기 전용 출력 권한.
- 명부 대상 Vitest, 변경 파일 ESLint, TypeScript/Vite 빌드 및 `git diff --check`.

## 완료 기록

- 생일 월·이름 필터를 추가하고, 월 선택에 공용 Select를 사용했다. 필터는 좌측의 제한된 폭으로 배치하고 검색 입력과 월 선택의 높이를 맞췄다.
- 조회 권한이 있는 사용자에게 선택 체크박스를 제공하고, 읽기 전용 사용자는 선택·PDF 출력만 할 수 있게 했다. 관리자의 선택 수·삭제 컨트롤은 PDF 저장 버튼 옆으로 옮겼다.
- 단일 PDF 저장 버튼과 범위 선택 Dialog를 추가했다. Dialog에서 선택 회원 또는 필터 결과 전체를 고르고, 대상 수를 확인할 수 있다.
- 브라우저 인쇄 화면에서 PDF로 저장할 때 이름·생년월일·등록된 이메일·전화번호를 포함하고, 이메일 열을 생년월일보다 넓게 설정했다.
- UI 문구는 한국어·영어·독일어를 지원한다.

## 검증 결과

- 명부 관련 Vitest 4개 파일, 9개 테스트 통과.
- TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 변경 TypeScript 파일 ESLint 및 `git diff --check` 통과.
