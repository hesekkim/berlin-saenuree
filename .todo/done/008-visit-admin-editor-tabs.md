# 008. Visit 관리자 편집기 탭 분리

- 상태: 완료
- 유형: 관리자 UX

## 목적

Visit 관리자 편집 화면의 긴 입력 흐름을 예배 일정과 위치 정보 탭으로 나눠, 편집할 정보를 쉽게 찾을 수 있게 한다.

## 범위

1. 예배 일정과 위치 정보를 접근 가능한 탭으로 분리한다.
2. 예배 일정 탭에는 예배 일정 관리만 표시한다.
3. 위치 정보 탭에는 주소, 대중교통, Google 지도 링크, 지도 스크린샷, 예배 장소 사진을 표시한다.
4. 탭을 전환해도 양쪽 입력값, 업로드 상태와 편집 상태를 유지한다.
5. 저장·업로드 진행 상태·오류·충돌 및 저장 버튼은 기존처럼 하나로 통합하고, 저장 한 번으로 모든 변경을 함께 반영한다.
6. 탭 UI 문구는 한국어·영어·독일어를 지원하고 키보드 조작을 제공한다.

## 제외 범위

- 공개 Visit 페이지 구성 변경
- 예배 일정과 위치 정보의 별도 API 또는 저장
- 미디어 업로드·정렬·정리 동작 변경

## 완료 조건

- 편집 화면에서 예배 일정과 위치 정보 탭을 전환할 수 있다.
- 선택되지 않은 탭 패널은 화면에서 감춰지지만 컴포넌트는 유지되어 편집 중 상태가 초기화되지 않는다.
- 탭 전환 후에도 입력값과 업로드 컴포넌트가 유지된다.
- 단일 저장 버튼과 기존 저장·오류·충돌 동작이 유지되고 모든 탭의 내용이 함께 저장된다.
- 탭의 접근성 이름, 선택 상태, 키보드 이동을 지원한다.
- 관련 frontend 단위 테스트, 타입 검사 및 lint가 통과한다.

## 검증

- 예배 일정과 위치 정보 탭 왕복 중 입력·업로드 상태 유지 확인
- 탭 키보드 이동과 선택 패널의 접근성 상태 확인
- 저장 로직과 관련 frontend 테스트, 빌드·타입 검사·lint 실행
