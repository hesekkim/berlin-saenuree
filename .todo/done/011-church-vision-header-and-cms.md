# 011. 교회 비전 헤더와 CMS 정리

- 상태: 완료
- 유형: 페이지 개선
- 선행 작업: [009-church-vision-page.md](./009-church-vision-page.md)

## 목적

교회 비전 페이지에서 페이지명과 본문 제목의 중복을 없애고, 핵심 비전 문구를 공통 페이지 헤더에 표시한다. CMS 편집 화면도 중복 제목 없이 비전 항목을 편집할 수 있도록 정리한다.

## 범위

1. 공개 페이지 헤더에 “예배는 선교의 동력이자 선교의 목표” 문구를 표시하고, 기존 `교회 비전` 헤더 제목은 제거한다. 영어·독일어 문구도 지원한다.
2. CMS의 페이지 소개 문구 필드와 교회 비전 `heading` 콘텐츠를 프론트엔드 모델, 편집기, 백엔드 정규화 및 JSON 데이터에서 제거한다. 기존 저장 데이터의 `heading`도 API 응답·저장 결과에서 제외한다.
3. CMS 페이지 제목과 중복되는 비전 목록 제목을 제거하고, 비전 추가 버튼은 오른쪽 끝에 정렬한다.
4. 공통 `PageHeader`를 사용하는 페이지 제목의 문장 끝 마침표를 제거해 표기를 통일한다.

## 완료 조건

- 공개 교회 비전 페이지에 핵심 비전 문구가 헤더로 표시되고 중복된 소개 제목은 나타나지 않는다.
- CMS 편집기에 페이지 소개 문구 입력란과 중복된 비전 목록 제목이 없다.
- CMS 비전 항목 추가 버튼이 오른쪽 끝에 정렬된다.
- 교회 비전의 `heading`은 JSON과 API 출력에서 제거되며 기존 데이터에 남아 있어도 노출되지 않는다.
- 공통 페이지 헤더 제목 문구의 마침표 표기가 통일된다.
- 관련 프론트엔드·백엔드 테스트와 프론트엔드 빌드가 통과한다.

## 검증 및 리뷰

- 프론트엔드 빌드 및 타입 검사 통과
- Church Vision 프론트엔드 단위 테스트 5개 통과
- Church Vision 백엔드 테스트 2개 통과
- 변경 파일 ESLint 검사 통과
- 코드 리뷰에서 수정이 필요한 문제 없음
